# Nexulabs photo library

Photos you've chosen for the posts. The scheduled runs use one roughly every third post, add the Nexulabs type and logo, and credit the photographer.

## Adding photos (phone or computer)
1. On unsplash.com, open a photo you like and download it (the **Medium** or **Large** size is plenty).
2. Rename it to the photographer's name, e.g. `jane-smith.jpg` (it's shown under the photo on Unsplash). This is used for the credit.
   - Optional: add a few words after two dashes to describe it, e.g. `jane-smith--laptop-on-desk.jpg`.
3. Go to github.com/wheatus2/nexulabs-social/tree/main/photos, choose **Add file → Upload files**, drop the photos in and press **Commit changes**.

## Good photos for Nexulabs
Workspaces, laptops/phones (screens blank or blurred), UK shopfronts and trades, tools, textures, architecture, North East scenery. Calm, uncluttered, with space for text.
Avoid: faces as the main subject, visible brand logos, screens showing real websites.

Used photos are moved to `photos/used/` so they're never repeated.
